## Decisions
- **Restore by git checkout in place** (planner did it): `git init` + fetch + `checkout -B main origin/main` in the owner folder. Rejected: cloning to a new folder (PROJECTS.md already names this folder as owner).
- **Next version is 0.2.2, maintenance only.** 0.3.0 features wait for the owner's request (they asked to get current first). Rejected: starting the planned 0.3.0 order now.
- **Perf work is evidence-gated, not assumed.** Recon says scripts cost 0.44 ms/frame and render submission ~3.1 ms on a 9800X3D/4080; the two untouched levers visible from runtime stats are 356 `AlwaysAnimate` animators and 8.4k shadow casters. Each gets a measured gate (T06/T07). Rejected: GPU Resident Drawer (needs BatchRendererGroup shader variants the player build likely stripped; not switchable at runtime safely), editing `boot.config` gfx-threading-mode (game file).
- **`CullUpdateTransforms`, never `CullCompletely`**: keeps the state machine and animation events running off-screen so FSM/logic that waits on animation states still progresses.
- **Gamepad tested with a virtual device** through the Input System (`InputSystem.AddDevice<Gamepad>()`), same path as hardware. Rejected: leaving gamepad untested again.
- **Reproducible builds via PathMap** so a rebuilt DLL can be compared with a released one.
- **Arrest keeps job progress** (current behaviour) until the owner decides otherwise; not blocking.
