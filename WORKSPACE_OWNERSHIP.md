# Ownership

Owner folder for the MSN2 Community Patch + MSN2 Expansion (My Sexy Neighbour 2, Steam 3684710). Public name: SenjuWoo.
- One active snapshot, named in CURRENT.txt. Older snapshots are immutable rollback copies.
- `research/` holds decompiled game code and review dumps: local reference only, never published.
- `vendor/` holds third-party downloads (BepInEx). `backups/saves/` holds automatic save backups made by tools/launch.ps1.
- Game folder: only BepInEx + `BepInEx/plugins/MSN2/` are written (tools/install.ps1); tools/uninstall.ps1 removes them.
